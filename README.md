# CSE 412: Software Engineering

This repository documents my coursework, laboratory exercises, assignments, and mini-project work for **CSE412 – Software Engineering** at East West University.

It serves as a structured record of my learning journey through the complete Software Development Life Cycle (SDLC), including process models, Agile methodologies, software design principles, architecture, testing strategies, and project management practices.

---

## 🎯 Course Objectives

* Understand and compare different software process models (Waterfall, V-Model, Spiral, Agile, etc.)
* Apply Agile methodologies such as Scrum and XP in development workflows
* Learn and implement software design patterns (creational, structural, behavioral)
* Analyze software architecture styles and system design principles
* Explore software testing techniques and quality assurance methods
* Study software project planning, estimation, and risk management
